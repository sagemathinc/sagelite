# sagelite-database-symbolic-data

Optional SymbolicData database companion package for `sagelite`.

This package contains the `database_symbolic_data` payload from SageMath 10.9,
installed as a Python wheel.  Installing it makes Sage's
`database_symbolic_data` optional doctests and `SymbolicData` ideal lookups
available without making the data a hard dependency of `sagelite`.

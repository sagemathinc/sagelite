# sagelite-database-odlyzko-zeta

Optional Odlyzko zeta zero database companion package for `sagelite`.

This package contains the `database_odlyzko_zeta` payload from SageMath 10.9,
installed as a Python wheel.  Installing it makes Sage's
`database_odlyzko_zeta` optional doctests and `zeta_zeros()` available without
making the data a hard dependency of `sagelite`.

# sagelite-database-stein-watkins-mini

Optional Stein-Watkins mini database companion package for `sagelite`.

This package contains the `database_stein_watkins_mini` payload from SageMath
10.9, installed as a Python wheel.  Installing it makes Sage's
`database_stein_watkins` optional doctests and `SteinWatkinsAllData` /
`SteinWatkinsPrimeData` lookups available without making the data a hard
dependency of `sagelite`.
